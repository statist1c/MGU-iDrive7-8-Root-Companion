# v0.4.0 — Experimental Android release

- Standalone APK; no PC or Termux required at runtime.
- Setup, Monitor, Backups and SSH tabs with guided MGU setup.
- VIN/compatibility checks, typed authorization, logging and private-data export.

Full credit for the original rooting work goes to [cauliflowermossgrape/idrive7-8-ssh-root](https://github.com/cauliflowermossgrape/idrive7-8-ssh-root). This is an Android adaptation of that project.

**Experimental:** build/emulator checks passed; no physical phone or BMW head-unit validation. Flashing can damage the module, erase coding and remove Digital Key pairings. Read the README and validation notes before use.

Install the attached APK. If updating from the previous standalone version, install over it without uninstalling to retain private app data.
